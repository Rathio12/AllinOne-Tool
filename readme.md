# ⚡ REY STATION V4.0
**The Ultimate Windows Native Optimized Utility**

A powerful Python-based toolkit designed to clean, monitor, and optimize Windows performance using low-level WinAPI calls.

### 🌟 Key Features:
- 🧹 **RAM & Cache**: Trim working sets and clear standby lists via `ntdll`.
- ⏱ **Power Timer**: Scheduled power actions with a high-fidelity TUI.
- 💾 **Disk & Junk**: Automated cleanup and health diagnostics.
- 📊 **Live Monitor**: Real-time CPU/RAM tracking and process management.
- 🌐 **Network**: Stack reset and DNS flushing tools.

### 🛠 Tech Stack:
- **Python** (Core Logic)
- **WinAPI / ctypes** (Native System Control)
- **Rich** (Premium Terminal UI)
